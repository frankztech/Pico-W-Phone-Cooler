# Pico-W-Phone-Cooler
A Raspberry Pi Pico W controlled cooling stand that uses a small fan to reduce phone temperature while charging, triggered by iPhone Shortcut automations.

## Goal
Control a 5V fan automatically while a phone is charging. Use an iPhone Shortcut to send a web request to the Raspberry Pi Pico W to start or stop the fan. Eventually design and 3D print a stand using SolidWorks.

## Features to implement
- Pico W runs a tiny web server
- iPhone Shortcut triggers fan on charging
- Basic MOSFET switch for fan control
- Later: PWM speed control
- Later: Tachometer readout
- Later: SolidWorks 3D printed stand

## Hardware
- Raspberry Pi Pico W
- 5V 4 pin fan
- NPN transistor or MOSFET
- USB power or external supply
- Breadboard and jumper wires
